# ComfyUI-Prompt-Assembler（提示词组装器）

按顺序组装提示词片段。库用「路径/层级」组织，输出顺序由组装区决定，两者解耦。

## 为什么

- 提示词片段需要被**按你自己的顺序**拼起来，而不是按点击顺序或字母顺序。
- 片段需要**层级归类**，比如 `角色/紫罗兰/常服1/上身服设`。
- 有些模型（如 Krea 2，文本编码器是 Qwen3-VL）吃自然语言，**A1111 权重语法无效**，所以输出必须是纯文本，不能带 `(x:0.85)`。
- 同一角色在不同镜头下要开关不同部位（比如转身就得关掉面部五官描述），所以要能逐条启用/禁用，还能存成预设。

## 安装

无需额外依赖（PyYAML 通常已随 ComfyUI 安装）。把整个 `ComfyUI-Prompt-Assembler` 目录放进 `ComfyUI/custom_nodes/`，重启 ComfyUI。

首次运行会用 `examples/library.yaml` 生成一份默认词库 `library.yaml`（若不存在）。

节点在 `text` 分类下：**提示词组装器 (Prompt Assembler)**。

## 词库

词库是节点目录下的 YAML 文件，可以直接手改：

```yaml
separator: ", "

items:
  - path: 角色/紫罗兰/常服1/上身服设   # 用 / 分层，层级随便加
    label: 上身                      # 短名，显示用
    text: "white blouse with a ribbon tie"   # 输出原文，不加权重
```

`path` 决定它在树里的位置；`label` 是显示名；`text` 是最终进入 prompt 的文本。

在面板里 **双击条目的短名或文本** 可以直接改（改完记得点“保存词库到文件”；改短名会自动同步组装区和预设里对该条目的引用，链接不会断）。鼠标移到**目录名**上会出现 ✎ 时，点它可重命名目录（会同步更新该目录下所有条目的路径，以及组装区/预设里的引用）。

**移动条目**：把一个条目**拖到某个目录名上**就移入该目录；拖到**另一个条目上**就移入它所在的目录；拖到左侧**空白处**则移到根目录。移动同样会同步组装区/预设里的引用。

**支持多份词库。** 节点包目录下所有 `*.yaml` 都算一个词库。左侧目录默认**折叠**，你展开/收起的状态会记住（下次打开面板或重开工作流保持一致）。在面板顶部的 **词库** 下拉里选，选择存在**当前节点**里（跟着工作流走），所以不同工程可以用不同的词库，互不影响。点 **新建词库** 会从当前词库拷贝一份新文件并切过去。新建文件后如果想在别的节点里也看到，按 `R` 刷新节点定义或重启 ComfyUI。

**分隔符**（面板顶部）决定片段之间怎么拼：框里用转义写法，`\n` 表示换行、`\n\n` 表示空行（两个换行），也可以填逗号等任意字符串。

## 用法

1. 把节点拖进画布，点节点上的 **打开组装面板**。面板顶部可选择/新建词库。
2. 加入组装区有两种方式：**点条目左侧的 ＋**，或**把条目拖进右侧组装区**（拖动时会有一条蓝色横线标出插入位置，上半行=插到它前面，下半行=插到后面）；点条目本身不会加入。也可用搜索框过滤。
3. 组装区里**拖动**排顺序，勾选框**启用/禁用**单条，`✕` 移除。
4. **临时修改**：点行尾的 `临时修改` 标记，或**双击该行文本**，改完只影响当前组装，**不会写回 `library.yaml`**。改过的行会变黄、标记变成 `已改 ↺`，点它可以还原为词库原文。**内容没变则不算修改**；把文本改回与词库一致也会自动取消“已改”。双击行首的**显示名**还可临时改名（只改这里的显示，不动词库、不影响输出；留空则恢复原名）。
5. **分组**：点 **＋分组** 建一个分组（默认折叠）。分组是一个**容器**，只装它里面的条目；组外也可以有顶层条目，所以可以在**分组之间或末尾**插入条目。分组头左侧有个**分组开关**：关掉后整组不参与输出（**不改成员自身的开关**）。词条只有在**自身启用、且所有上级分组都启用**时才会被插入。`▾/▸` 展开收起，双击标题改名，`✕` 解散（成员提到上一层保留）。把条目**拖到分组头中间**即放进该分组（会自动展开），拖到分组头**上/下边缘**则作为它的同级插入；拖动分组头会连同成员整体移动；从树里加条目时，如果某个分组名是该条目路径的前缀（例如分组叫 `角色/紫罗兰`），会自动加进那个分组。
6. 需要临时文字（例如 `Picture 1:`）就用左下 **插入固定文本**。
7. **预设**：把当前组装存成命名预设（存在当前节点里），一个节点可以有多套，随时切换。
8. 点 **应用到节点**，节点输出即按组装区顺序拼接好的纯文本。（节点上的预览框是**只读**的，内容由面板生成，不能手改。）

在面板里新增/删除的条目要点 **保存词库到文件** 才会写回 `library.yaml`。

## 输出

节点输出 `prompt`（STRING）。可选输入 `prefix` / `suffix` 会按同一个分隔符拼在最前/最后。

顺序示例：组装区里排成 `画质 → 角色/整体 → 上身 → 下身 → 光照`，输出就是

```
masterpiece, best quality, highly detailed, violet, casual outfit, ..., golden hour backlight, warm rim light
```

## 和 Krea 2 配合

- 输出纯文本，无权重括号，直接接到 `TextEncodeKrea2Reference` 或普通 prompt 节点。
- 「转身看不到脸」这类需求：把常用部位都放进组装区，需要转身时禁用 `角色/紫罗兰/面部/面部五官`。
- 把这些组合存成预设（正面 / 背身 / 特写），切换镜头时直接载入。
